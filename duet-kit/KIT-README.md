# Duet Kit — how to use

1. Create the repo folder, e.g. `duet/`, and `git init`.
2. Copy into the repo root: `CLAUDE.md`, `AGENTS.md`, `DESIGN.md`, `docs/`, `.claude/`.
3. Open Claude Code in the repo root.
4. Paste the contents of `PROMPT.md` (everything below the line) as your first message.
5. Let it finish Phase 0–1, test by hand, then say "Proceed to Phase 2" and so on.

Free accounts you'll need: Supabase, Vercel or Cloudflare Pages, a free TURN provider (Metered or Cloudflare). Android Studio for the APK. Rust + Tauri prerequisites for Windows builds.

Tip: rename "Duet" anywhere you like. It's a working title.
